# 편의점 문제

## 개요 - 구매자의 할인 혜택과 재고 상황을 고려하여 최종 결제 금액을 계산하고 안내하는 결제 시스템을 구현한다.
- 방식 : 사용자 시나리오 방식
- 사용자 시나리오 : 초기 로드→장바구니 담기(입력)→프로모션 상품 확인→멤버십 할인→최종 결제 금액→영수증출력

### 초기 로드

- [ ] 상품 목록과 행사 목록을 불러온다. (형식 유지, 값 수정 가능)(`products.md`, `promotions.md` )
- [ ] 프로모션 기간 설정, 오늘 날짜가 프로모션 기간에 포함되는지 확인
- [ ] 인사말 & 상품 목록 출력

### 장바구니 담기(입력 및 검증)

- [ ] 구매할 상품과 수량 입력.
(상품명, 수량은 하이픈(-)으로, 개별 상품은 대괄호([])로 묶어 쉼표(,)로 구분한다.)

### 프로모션 상품 확인

- [ ] 증정 안내 (Y|N)
- [ ] 프로모션 재고 부족으로 일반 재고로 원가 계산 안내 (Y|N)
- [ ] 프로모션 재고 우선 차감
- [ ] 행사 기간 확인하여 증정

### 멤버십 할인

- [ ] 적용 안내 (Y|N)
- [ ] 프로모션 미적용 상품에 한해 30% 할인
- [ ] 최대 한도 8,000원

### 최종 결제 금액

- [ ] 총구매액(원가) 결제 금액 계산
- [ ] 행사 할인 금액 계산
- [ ] 멤버십 할인 금액 계산
- [ ] 내실 돈 계산 (총구매액 - 행사할인 - 멤버실할인 = 내실 돈)

### 영수증 출력

- [ ] 증정품 내역 출력
- [ ] 총구매액(원가) 결제 금액 출력
- [ ] 행사 할인 금액 출력
- [ ] 멤버십 할인 금액 출력
- [ ] 내실 돈 출력 (원가 - 행사할인 - 멤버실할인 = 내실 돈)

### 재고 업데이트

- [ ] 구매한 상품 수량만큼 재고에서 차감

### 추가구매 및 종료

- [ ] 영수증 출력 후 Y이면 추가구매
    - [ ] 갱신된 재고 목록 출력
- [ ] 영수증 출력 후 N이면 종료
